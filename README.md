# Лабораторная работа №2: Базовые и продвинутые возможности CSS

## Цель работы

Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

## Что реализовано
- **Примеры позиционирования**:
  - `position: static` — `body.page-main`;
  - `position: relative` — `.card-inner` (карточки проектов);
  - `position: absolute` — `.nav-link` в шапке страницы Варианта 10.
- **Состояния элементов**:
  - `:hover` — ссылка навигации, карточка проекта, кнопка формы;
  - `:active` — кнопка отправки формы;
  - `:focus` — поля формы;
  - `:visited` — ссылка навигации.
- **Контрастность текста** — подобраны цветовые пары не менее 4.5:1 (основной текст на светлом фоне карточек и страницы).

## Вариант 10. Тема «Книжный червь и писатель» (эффект переворота страницы)

- Карточки проектов (`.project-card`) переворачиваются при наведении (`transform: rotateY(180deg)`): лицевая сторона — название и автор, обратная — краткое описание.
- При `:focus` на поле «Имя» рамка поля пульсирует (`@keyframes pulse`, изменение `border-color` и `box-shadow`).
- Цветовые переменные: основной — бежевый (`--beige-light`), акцент — коричневый (`--accent-brown`).
- Inline-стиль `max-width: 100%` применён к изображению.
- Стили для нумерованного списка проектов (кастомные отступы и нумерация через `counter()`).

## Используемые технологии (ЛР №2)
- CSS3: переменные (`:root`), позиционирование, псевдоклассы, `@keyframes`-анимации, 3D-трансформации (`perspective`, `rotateY`, `backface-visibility`).
